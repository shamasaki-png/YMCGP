# アルコールチェック記録簿（GitHub Pages + Googleスプレッドシート）

構成：`index.html`（GitHub Pagesで公開）→ `Code.gs`（Apps Script ウェブアプリ）→ スプレッドシート（DB）＋Driveフォルダ（写真）

## セットアップ
1. `alcohol-check-db.xlsx` をGoogleドライブにアップロードし、「Googleスプレッドシートとして保存」で変換する。
2. シート「従業員」のサンプル行を削除（または書き換え）し、「車両」を実際の内容にする。管理者にしたい人は、「従業員」シートの権限欄を手動で「管理者」にする。運転者は、アプリの最初の画面で自分で名前とPINを登録できる（権限は自動で「従業員」）。
3. 写真保存用のDriveフォルダを作り、URL末尾のフォルダIDを控える。
4. スプレッドシートで「拡張機能 > Apps Script」を開き、`Code.gs` を貼り付けて `FOLDER_ID` を設定する。
5. 「デプロイ > 新しいデプロイ > ウェブアプリ」：実行ユーザー＝自分、アクセスできるユーザー＝全員。初回は権限を承認する。表示されたURLをコピーする。
6. `index.html` 冒頭の `API` にそのURLを貼り付ける。
7. GitHubにリポジトリを作成して `index.html` をアップロードし、Settings > Pages で公開する。
8. 従業員のiPhoneでURLをSafariで開き、共有ボタンから「ホーム画面に追加」。

## 注意
- 車両は、ログイン後の「チェック入力」画面で「新しい車両を登録」から誰でも追加できる（「車両」シートに自動追加）。誤登録は、「車両」シートの該当行を削除する。
- 登録済みの運転者は、最初の画面のプルダウンから氏名を選び、PINを入力してログインする（端末に記憶され、次回から自動入力）。PINを忘れた場合は、「従業員」シートで管理者が書き換える。
- 名前の重複登録は拒否される。誤登録は、「従業員」シートの該当行を削除する。
- Code.gs を修正したら「デプロイを管理」から新バージョンで再デプロイする。
- 従業員は自分の記録のみ閲覧可、管理者は全件閲覧・確認可（サーバー側で判定）。
- PINはスプレッドシートに平文で入るため、シートの共有は管理者のみにする。
- 写真はDriveフォルダに保存され、アプリ経由でのみ表示される（フォルダは非公開のまま）。
- 記録はスプレッドシートの「記録」シートで直接集計・CSV出力できる。
